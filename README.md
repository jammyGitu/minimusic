# Minimusic 音乐学习软件

一个专业的音乐学习与练习平台，基于 Next.js 14 开发。

## 🎵 核心功能

### 1. 音程辨认练习
- 听两个音判断音程关系
- 支持12种音程类型
- 实时统计正确率

### 2. 和弦辨认练习
- 听和弦选择正确的和弦类型
- 支持三和弦和七和弦
- 提升和声听觉能力

### 3. 虚拟钢琴
- 交互式钢琴键盘
- 支持C3-C6音域
- 实时发声体验

### 4. 学习进度追踪
- 练习统计和成就系统
- 连续练习天数追踪
- 历史记录查看

## 🚀 技术栈

- **框架**: Next.js 14 (App Router)
- **UI**: Ant Design + Tailwind CSS
- **音频**: Tone.js
- **状态管理**: Valtio
- **语言**: TypeScript

## 📦 安装和运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```
